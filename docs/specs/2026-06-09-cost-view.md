# 2026-06-09 — Leah cost-observation surface

Status: shipped (Phase 1)
Phase: self-host (single operator)
Owner: tri@maydow.com

## 1. Goal

Operator sees Leah + Anthropic-API spend over time without leaving the
terminal. Same data already lives in `audit.jsonl` per row (`cost_dollars`);
no upstream change required.

Non-goal: degrade-ladder enforcement (that lives in `internal/budget`), anomaly
detection, multi-operator rollup, currency conversion.

## 2. Data sources

Primary — `~/.leah-state/audit.jsonl`. One row per CLI invocation; each
row carries `cost_dollars` (set by `dispatcher.{Ask,Ship}` / `cmd/leah/main.go::runReview`
from `budget.Budget.Spent()` after the call returns). Aggregation = sum
across rows filtered by `--since`.

Secondary — `obs/metrics.go::leah_budget_spent_usd` gauge (per-process, in
memory; the dashboard already surfaces the live daemon's value via `OpsView.BudgetSpent`).

Deferred (Phase 2) — Anthropic billing API reconciliation. As of `anthropic-go-sdk` v0.x there is no `client.Billing.*`
surface; reconciliation would require a hand-rolled HTTP call against
`https://api.anthropic.com/v1/organizations/{org}/usage_report/messages` plus
an Admin API key (separate scope from the message-completion key). Path is
documented but not implemented; reopen when Admin-API access is provisioned.

## 3. CLI shape

```
leah cost [--since DURATION] [--by kind|day|model] [--json]
```

- `--since` accepts Go duration (`24h`, `7d`, `30d`, `720h`). Default: `30d` (interpreted as 30×24h).
- `--by kind` groups by audit row `kind` (ask, ship, review, ...).
- `--by day` groups by UTC date string (`YYYY-MM-DD`).
- `--by model` groups by the model id when present (audit rows lacking the field bucket into `unknown`).
- `--json` emits the full Summary struct; default is a terse 2-column table.
- Default (no `--by`) prints: total $, count, top-3 kinds.

## 4. Dashboard integration

OPS quadrant gains 3 lines: `cost today`, `cost 7d`, `top kinds`. Snapshot
computes via `costview.Aggregate` on each `/api/state` poll (3s cadence,
audit.jsonl tail is bounded by row count — streaming bufio.Scanner is
adequate for 10K rows in <5ms). No new quadrant.

Loopback bind already enforces local-only. Cost data is operator-private
and never leaves 127.0.0.1.

## 5. Build order

1. `internal/costview/{aggregate.go,aggregate_test.go}` — pure Go, streaming
   parse, no I/O beyond `os.Open` + `bufio.Scanner`.
2. `cmd/leah/cost.go` + `cmd/leah/main.go` switch case — flag parsing +
   terse / JSON output.
3. `internal/web/state.go` — add `CostsView` to State; dashboard.js renders
   3 new lines under OPS.

## 6. Cuts

- No per-tier-degrade ladder enforcement here (lives in budget gate).
- No anomaly detection / threshold alerts (Phase 2).
- No SQLite materialization — streaming parse over append-only JSONL is
  fast enough at single-operator scale. Reopen when audit row count
  exceeds 100K (≈ 30 minutes of parse time at current rate).
- No Anthropic billing API call (SDK gap; Admin-API key not provisioned).
- USD-only; multi-currency conversion deferred.

## 7. Adversarial review (severity-tagged)

HIGH — Audit `cost_dollars` accuracy: `runReview` writes `b.Spent()` from
the per-process budget; reviewer subagent runs in the same process so its
cost is folded in. Sub-second collision is impossible because every CLI
invocation creates a new audit row (timestamp resolution is RFC3339 second-
level but multiple invocations within the same second are still separate
rows — sum is correct, `--by day` keyed by date string is correct,
`--by kind` is correct).

MED — Audit log rotation: operator may rotate `audit.jsonl` manually
(unzip + truncate). The cost view will under-report. Mitigation: document
that `cost --since` should be set within the current log's retention
window; consider future `audit.jsonl.1` glob (deferred).

MED — Model field is not on the Entry today. `--by model` will return
`{"unknown": <total>}` for current rows. Surface added now so future Entry
extension (`Model string` field) auto-populates without touching this layer.

LOW — `--since 30d` parsing: stdlib `time.ParseDuration` does NOT accept
`d` suffix. Handled in cost.go by recognizing `Nd` and converting to
`N*24h` before delegating to ParseDuration.

LOW — Currency assumed USD. Anthropic bills in USD; no FX layer required
in Phase 1.

LOW — Performance: 10K rows × ~150 bytes/row = ~1.5MB; streaming parse
benchmarked at <10ms on the operator's machine.

LOW — Privacy: cost view leaks how often operator uses Leah, but
dashboard is 127.0.0.1-only and audit.jsonl is 0600-permissioned.

## 8. Anthropic billing API reconciliation (Phase 2 sketch)

When Admin API key surfaces:

```go
// internal/anthropicbilling/client.go
//   GET https://api.anthropic.com/v1/organizations/{org}/usage_report/messages
//   Header: x-api-key: <ADMIN_KEY>
//   Header: anthropic-version: 2023-06-01
// Response: { data: [{ starting_at, ending_at, model, input_tokens,
//                      output_tokens, cache_creation_input_tokens,
//                      cache_read_input_tokens }, ...] }
```

`leah cost reconcile --since 7d` would diff the local aggregate against
the Anthropic-reported aggregate and print the delta. Reopen-trigger:
operator provisions an Admin API key.

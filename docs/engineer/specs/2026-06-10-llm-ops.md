## 1. Goal

Every LLM call Leah issues — reasoner, intent, eval judge, voice
shape — MUST be observable along its actual cost dimension: prompt-
version, model, token counts, latency, dollars, egress bytes. A
monthly cost gauge survives daemon restarts and a circuit breaker
degrades model selection before the operator's monthly spend hits the
cap.

Goals: hash every prompt at load → `prompt_sha` label; adopt
OpenLLMetry `gen_ai.*` OTel semconv; extend `audit.Entry` with six
fields (additive, back-compat); persistent monthly cost gauge with
rollover; circuit breaker (80 % warn → Sonnet→Haiku for non-merge;
100 % deny); HUD tile for monthly spend + runrate.

Non-goals (v1): per-prompt A/B routing or DSPy optimization (P2
reject); cross-vendor cost normalization beyond `Client.Complete`
return; per-conversation budget (the `internal/budget` per-process
ceiling remains the in-flight gate).

## 2. Audit schema additions (additive, back-compat)

`internal/audit.Entry` grows seven `omitempty` fields. Existing readers
(`patterns.Detect`, `selflearn.Resolver`, `operatormodel.Observe*`,
`web.Snapshot`) decode historic rows unchanged because
`encoding/json` ignores unknown fields and missing fields zero-value.

```go
type Entry struct {
    // existing fields unchanged.
    Model        string `json:"model,omitempty"`         // e.g. "claude-sonnet-4-6"
    PromptSHA    string `json:"prompt_sha,omitempty"`    // sha256[:16] of system prompt bytes
    InputTokens  int    `json:"input_tokens,omitempty"`
    OutputTokens int    `json:"output_tokens,omitempty"`
    LatencyMS    int64  `json:"latency_ms,omitempty"`
    EgressBytes  int64  `json:"egress_bytes,omitempty"`  // request body bytes (gated, §12)
    CacheHit     bool   `json:"cache_hit,omitempty"`     // cache_read_input_tokens > 0 (§12)
}
```

Semantics: `Model` is provider-pinned id at call time. `PromptSHA` is
first 16 hex of SHA-256 of **system-prompt bytes only** (§4) — persona
prefix (per-workspace overlay) is excluded so audit-replay can resolve
the SHA back to a registry entry. `InputTokens`/`OutputTokens` are
provider-reported, not estimated. `LatencyMS` is wall time of
`Client.Complete`, including retries. `EgressBytes` is request body
bytes sent (Ollama records 0); gated behind `LEAH_AUDIT_EGRESS_BYTES=1`
because the SDK does not expose the wire payload and deriving it
requires a parallel marshal — opt-in keeps the CPU cost off the hot
path for operators who don't need byte-level egress accounting.
`CacheHit` is true iff Anthropic returned `cache_read_input_tokens > 0`
(§12); paired with `Model` it lets retro distinguish cold-vs-warm
calls without re-reading the Usage block. A
`TestEntry_BackCompatDecodeLegacy` fixture (pre-W92 audit.jsonl row)
MUST round-trip cleanly in the W92 PR.

## 3. Prometheus metric series

Registered against `internal/obs.Registry`. Cardinality budget:

- `prompt_sha` values ≤ 200 (registry §4 hard-cap via boot-time enum).
- `model` values ≤ 8.
- `kind` values ≤ 6 (`reasoner`, `judge`, `intent`, `brief`,
  `voice_shape`, `self-build`). The `self-build` label matches the
  existing audit-row `Kind` (see `internal/learn/dangling_selfbuild.go`)
  so downstream joins (`patterns.Detect`, `selflearn.Resolver`,
  retro queries) match without label rewrites.

Worst-case 200 × 8 × 6 = 9 600 series exceeds the
`observability.md §4.14` 5 000 cap. Mitigation: `prompt_sha` only on
the two reasoner series; coarser series drop the label. Net LLM-dim
cardinality ≈ 200 × 8 + 8 × 6 ≈ 1 650 — inside budget.

| Metric | Type | Labels |
|--------|------|--------|
| `leah_reasoner_call_total` | counter | `model`, `prompt_sha`, `outcome` |
| `leah_reasoner_tokens_total` | counter | `model`, `prompt_sha`, `direction` |
| `leah_reasoner_egress_bytes_total` | counter | `model`, `kind` |
| `leah_reasoner_latency_seconds` | histogram | `model`, `kind` |
| `leah_cost_month_dollars` | gauge | `kind` |
| `leah_cost_breaker_state` | gauge | (none) — 0 ok / 1 warn / 2 deny |
| `leah_cost_breaker_degrade_total` | counter | `from_model`, `to_model` |
| `leah_prompt_registry_loaded_total` | gauge | (none) |

`outcome`: `ok`, `error`, `budget_blocked`, `breaker_denied`.
`direction`: `input`, `output`.

Adding `prompt_sha` to existing series is a soft break for Prometheus
consumers (label set widens) — surfaced in the W92 PR body.

## 4. Prompt registry

### 4.1 Loading + hash

Lazy on first `Register(name)`, cached for process lifetime. Walking
`prompts/` in `init()` would couple every package importing reasoner
to a filesystem read at import time. Boot pre-populates so
`SelfCheck` can assert count > 0.

```go
func PromptSHA(b []byte) string {
    sum := sha256.Sum256(b)
    return hex.EncodeToString(sum[:8]) // 16 hex chars
}
```

Bytes are SHA'd as-loaded — whitespace included. 16 hex chars =
2⁶⁴-space, birthday-safe at single-operator scale.

### 4.2 In-memory shape

```go
type PromptRegistry struct {
    mu sync.RWMutex
    byName map[string]promptEntry  // name → entry
    bySHA  map[string]string       // sha → name (reverse lookup for audit replay)
}

type promptEntry struct {
    Name, SHA, Text string
    LoadedAt        time.Time
}
```

`Text` stays resident: ≤200 prompts × ≤10 KB ≈ 2 MB, smaller than
existing audit ring buffers. Justifications:
1. Replay — `leah audit replay <id>` reconstructs the exact system
   prompt without a `git show` against the prompt's commit SHA.
2. Anthropic prompt-cache marker (§12) needs the text in hand at call
   time anyway.

### 4.3 No runtime reload

Registry is immutable for the process. Prompt edits land via code PR
(in-repo) and PR merge implies daemon restart. Live-reload would
invite mid-call SHA flips that complicate replay.

### 4.4 Resident-size enforcement

The ≤200 × ≤10 KB ≈ 2 MB figure in §4.2 is a budget, not a
comment. `Register` MUST reject when
`total_registered_bytes + len(newPrompt) > 2*1024*1024` with a new
sentinel `ErrPromptRegistryFull`. No silent eviction (LRU would
surprise operators mid-call when a freshly-registered prompt
displaces a still-in-use one and audit replay can no longer
resolve the old SHA). Operators evict explicitly via `leah
prompt-registry evict --sha=<sha>`; W92 ships this CLI alongside
the Register guard. Required tests (W92):
`TestPromptRegistry_RejectsOverCapAt2MB` and
`TestPromptRegistry_EvictBySHAFreesBudget`.

Adopting the OTel GenAI semconv (OpenLLMetry upstream) means LLM

## 6. Monthly cost gauge persistence

### 6.1 State file

`~/.leah-state/cost-month.json`, mode `0600`:

```json
{
  "year_month": "2026-06",
  "operator_id": "default",
  "totals_by_kind": {
    "reasoner": 12.34, "judge": 1.20, "intent": 0.45,
    "brief": 0.10, "voice_shape": 0.00, "self-build": 3.50
  },
  "month_cap_dollars": 50.0,
  "last_charge_at": "2026-06-10T11:40:00Z",
  "rollover_at": "2026-07-01T00:00:00Z"
}
```

`operator_id` matches `audit.Workspace`; a future multi-operator
deployment shards into `~/.leah-state/cost-month/<operator_id>.json`.

### 6.2 Write path

Single goroutine owns the file. Every LLM call posts
`CostEvent{Kind, Dollars}` to a buffered channel (cap 256); the
updater mutates totals and writes via write-temp-then-rename (matches
`obs.Registry.Snapshot`). No fsync per event — rename gives crash-
atomicity for the most-recent persisted state; a lost write window
costs at most one event, recovered by the next call.

### 6.3 Rollover

Updater compares `time.Now().UTC().Format("2006-01")` against
`year_month` on every event AND on a 1-minute timer. Mismatch →
archive to `~/.leah-state/cost-month-archive/<year_month>.json`,
reset `totals_by_kind`, recompute `rollover_at`. Archive is append-
only history surfaced by `leah whoami --full` (S10). Daemon-idle
midnight rolls within ≤60 s.

### 6.4 Boot recovery

Open `cost-month.json`; missing → fresh start with current YM. YM
mismatch → rollover (§6.3). Populate gauges from `totals_by_kind`.
Corrupted JSON → archive to `cost-month-corrupt-<ts>.json` and start
fresh; hand-edits (daemon down) honored on next boot.

## 7. Cost circuit breaker

### 7.1 Thresholds

`month_cap_dollars` defaults to $50, env override
`LEAH_COST_MONTH_CAP`. State on `sum(totals) / cap`:

| Ratio | State | Behavior |
|-------|-------|----------|
| < 0.80 | `ok` | All calls proceed. |
| 0.80–1.00 | `warn` | Sonnet→Haiku swap for `intent`, `brief`, `voice_shape`, `judge`. Reasoner + `self-build` (merge-path) stay on Sonnet. HUD amber. |
| ≥ 1.00 | `deny` | All LLM calls return `*BreakerDeniedError` unless attested override (§7.3). HUD red. |

State published on `leah_cost_breaker_state`.

### 7.2 Graceful Sonnet→Haiku swap

`reasoner.Client` gains optional `Degrade(model) Client`.
`AnthropicClient` implements by cloning with a new `model`; Ollama
no-ops. Caller-side wiring in a thin `reasoner.Router`:

```go
type Router struct {
    Primary, Degraded Client
    Breaker *Breaker
    Kind string
}

func (r *Router) Complete(ctx, system, user) (string, float64, error) {
    if r.Breaker.State() == StateDeny {
        return "", 0, &BreakerDeniedError{Kind: r.Kind, Spent: r.Breaker.Spent(), Cap: r.Breaker.Cap()}
    }
    c := r.Primary
    if r.Breaker.State() == StateWarn && !mergeKind(r.Kind) {
        c = r.Degraded
        emitDegradeMetric(r.Primary.Model(), r.Degraded.Model())
    }
    return c.Complete(ctx, system, user)
}
```

`mergeKind(k)` is true for `reasoner` and `self-build` — operator-
facing or merge-gating. Other kinds degrade.

### 7.3 Operator override

`leah cost override --kind=reasoner --reason="<≥32 chars>"` (mirrors
eval-pipeline §11 attestation flow). Writes audit row
`Kind: "cost_override"`, sets 1-hour in-memory TTL on the breaker,
allows the overridden `kind` to proceed at Sonnet despite `deny`.
Restart re-imposes deny. Override audit rows survive the standard
30-day retention sweep (matches eval-override carve-out).

The attestation `cost_override` scope MUST be registered with
`attestation.Pool` at Load time. `attestation.Pool` is fail-closed
(`ErrUnknownScope` on `Pick` for an unregistered scope — see
`internal/attestation/pool.go`); an unregistered scope silently
breaks the override flow. W94 wires this at the existing Load
call-site in `internal/dispatcher/selfbuild.go::pickAttestationQuestion`
(currently `attestation.Load(path, selfBuildScope)` — extend to
`attestation.Load(path, selfBuildScope, costOverrideScope)`) OR
hoists the single `*attestation.Pool` into the daemon boot path
(`cmd/leah-daemon/`) if a second consumer makes shared ownership
cleaner; the spec is agnostic on the hoist, NOT on the registration.
Required test (W94): `TestAttestationPool_CostOverrideScopeRegistered`
loads the pool used by the cost-override command and asserts
`pool.Pick("cost_override")` returns nil error.

### 7.4 Compound budget precedence

Three ceilings layer at runtime: `internal/budget.DefaultCeiling`
($5/process, in-flight hard wall), `internal/eval/budget.go`
($15/week, eval-pipeline judge spend), and the new $50/month
operator-trust ceiling here. Precedence (innermost wins; outer
caps still apply):

1. **Per-process ($5)** — per-invocation hard wall. Blocks at
   `Spent ≥ Ceiling` regardless of outer state.
2. **Per-week ($15, eval-only)** — gates eval-pipeline judge spend
   only; reasoner / intent / brief / voice / self-build ignore it.
3. **Per-month ($50)** — operator-trust ceiling across all kinds.
   Alerts at 80 % (warn → Sonnet→Haiku for non-merge), refuses
   new spawns at 100 % (`StateDeny`) unless overridden (§7.3).

Worked case: monthly at 0.85 (`warn`), eval-weekly at 0.90, and a
judge call arriving. Eval-weekly is the tighter eval-scoped wall →
judge blocks on eval-weekly with `budget_blocked`, never reaches
the breaker. Warn-state breaker would have allowed Haiku, but the
inner eval cap fires first. Reverse: monthly at 1.0 (`deny`), eval
under cap, judge call arriving → `breaker_denied`. The
`outcome` label (§3) carries the precise gate that fired so
dashboards stay unambiguous.

## 12. Anthropic prompt-cache — non-cacheable boundary

Anthropic prompt-cache requires a `cache_control: {"type":"ephemeral"}`
breakpoint on a block whose prefix is **≥ 1024 tokens**. Below the
floor, the breakpoint is rejected and billing proceeds uncached.

### 12.1 Measure first

W93's first task: tokenize each prompt in `prompts/` (Anthropic
`count_tokens` or local tiktoken-compatible counter) and emit a one-
shot `leah_prompt_token_count{name}` gauge at boot. Prompts ≥ 1024
become caching candidates; smaller prompts stay uncached and are
documented as ineligible.

### 12.2 Plumbing (W96+, pre-wired here)

For eligible prompts, `AnthropicClient.Complete` SHALL set
`CacheControl: anthropic.CacheControlEphemeral{}` on the system
`TextBlockParam`. Provider returns `cache_creation_input_tokens` +
`cache_read_input_tokens` in `Usage`; reasoner records `cache_hit =
(cache_read > 0)` and sets `leah.cache_hit`. Cost: cached reads at
0.1× input rate, writes at 1.25× — pricing constants in `anthropic.go`
extend with two new fields and the cost calc splits.

Behind `LEAH_ANTHROPIC_PROMPT_CACHE=1` for one wave so rollout is
reversible if cache-read attribution diverges from invoiced cost by
> 5 %.

### 12.3 Why this lives in the obs spec

The §7 breaker thresholds calibrate against billed monthly rate.
Adopting prompt caching cuts the reasoner share 60–80 % (P1 brief
item) — measuring first prevents calibrating $50 against a soon-
shrinking denominator and tripping the breaker on the rollback path.

## 15. Notes (P2 / semantic)

- `prompt_sha` lives on only the two reasoner Prometheus series
  (§3 cardinality budget); operators who want per-reasoner cardinality
  on judge / intent / brief / voice / self-build series pivot in the
  OTel span (`leah.prompt_sha` attribute §5) — full per-kind
  cardinality without the Prometheus cost.
- Monthly rollover is UTC-pinned (§6.3) by design. Operator-local-
  midnight rollover is a P2 follow-up: requires a `tz` field in
  `cost-month.json` and a TZ-aware comparator; cardinality unaffected.
  No-op for the single-operator MVP-5 footprint.
- `gen_ai.response.id` is empty for Ollama spans (semconv requires
  the field, but Ollama does not return a message id). Span emission
  sets the attribute to `""`; OTel backends tolerate this. Anthropic
  + OpenAI populate normally.
